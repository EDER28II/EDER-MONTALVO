SUBIR A GITHUB
1. Crea un repositorio nuevo.
2. Sube todos estos archivos manteniendo la carpeta assets.
3. Ve a Settings > Pages.
4. Selecciona Deploy from a branch.
5. Elige main y / (root).
6. Guarda.
7. GitHub publicará la URL del sitio.

IMPORTANTE
- Verifica teléfono y datos de contacto antes de publicar.
- Si agregas correo, dirección, redes o herramientas analíticas, actualiza la información legal.
- No publiques testimonios, porcentajes de éxito o resultados que no puedan acreditarse.
